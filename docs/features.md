# 기능과 단계

vFlat Scan(https://vflat.com/ko)이 내세우는 기능을 모두 만들고, 팜플렛 정리를 더합니다. 품질은 단계마다 실제 팜플렛과 책 사진으로 비교합니다. 곡면 보정, 손가락 지우기, 필기 지우기는 vFlat 자체 모델이라 공개 모델로 같은 품질을 장담할 수 없습니다.

## vFlat 기능 대응

| vFlat 기능 | scanshelf | 처리 위치 | 단계 |
|---|---|---|---|
| 자동 인식 (테두리, 원근 보정) | Vision 테두리 감지 + `CIPerspectiveCorrection` | iPhone 표시, Mac 처리 | 1 |
| 자동 스캔 | 안정, 손, 중복 판단으로 자동 촬영 (docs/capture.md) | iPhone | 1 |
| PDF, JPG 내보내기 | 무제한, 공유 시트 | Mac | 1 |
| 텍스트 인식 (100개 이상 언어) | Apple Vision OCR, 기기 안 처리 | Mac | 1 |
| PC로 보내기, 클라우드 백업 | Wi-Fi 직접 + iCloud 폴더 (docs/transfer.md) | 둘 다 | 1 |
| 단어 검색, 텍스트 복사 | SQLite FTS5, 텍스트 레이어 PDF | Mac | 2 |
| 텍스트 파일 내보내기 | OCR 결과 | Mac | 2 |
| 두 페이지 | 가운데 접힌 선 찾아 분할 | Mac | 3 |
| 곡면 보정, 더 펴기 | UVDoc 계열 ONNX 모델, 더 펴기는 2차 보정 | Mac | 3 |
| 고른 조명 | 그림자 제거, 흰색 맞춤 | Mac | 3 |
| 손가락 지우기 | 손 영역 검출 + LaMa 인페인팅 | Mac | 4 |
| 필기 지우기 | 필기 분할 모델 + 인페인팅 | Mac | 4 |
| Word 내보내기 | OCR 단락 구조로 docx | Mac | 4 |

## scanshelf에만 있는 기능

| 기능 | 단계 |
|---|---|
| 볼륨 버튼, 블루투스 리모컨 셔터 | 1 |
| 촬영 세션(박람회명)과 문서 이름 자동 추천 | 2 |
| 팜플렛 AI 정리(`claude -p`)와 노션 CSV | 2 |

## 노션 CSV 열

회사명, 국가, 박람회명, 날짜, 주력 제품과 기술, 주요 스펙, 타깃 시장과 고객, 레퍼런스, 우리 회사와의 관련성(경쟁사, 협력 후보, 공급사), 연락처, 원본 파일명

관련성은 NULL SPACE(데이터센터 구축 로봇) 기준으로 AI가 판단합니다.

## 단계

1. 촬영(자동 스캔, 셔터) + 전송 + 원근 보정 + OCR + PDF, JPG 내보내기
2. 팜플렛 AI 정리 + 노션 CSV + 검색 + 텍스트 레이어 PDF
3. 두 페이지 분리 + 곡면 보정 + 조명 보정
4. 손가락 지우기 + 필기 지우기 + Word 내보내기

## 다음 단계 (2026-11-05 결정)

vFlat 기능 다음으로 만들 것입니다.

| 기능 | 내용 |
|---|---|---|
| 앱 안 업데이트 | Mac은 Tauri updater, iPhone은 AltStore 소스 (docs/update.md) |
| scanshelf MCP 서버 | Claude가 보관함을 찾고 OCR 원문과 팜플렛 정리를 읽음. 찾기와 읽기는 앱이 꺼져 있어도 됨 |
| 책 페이지 번호 검사 | OCR로 쪽 번호를 읽어 빠진 쪽과 겹친 쪽을 알리고, 그 쪽만 다시 찍어 끼움 |
| 접는 팜플렛 패널 분리 | 3단 접지를 펼쳐 찍으면 패널별로 나눔 |
| 문서에 질문하기 | 문서 하나 또는 모든 팜플렛에 묻기. 답의 근거에 `[D3 p.2]`처럼 문서와 쪽을 달고, 누르면 그 쪽을 엶 |
| 태그와 AI 정리 | `/` 계층 태그(예: `박람회/2026 DCK`, `분야/냉각`). Mac AI가 팜플렛에 분야 태그를 붙이고, 손으로 고친 태그는 덮지 않음 |
| 빠른 찾기, 우클릭 메뉴, 단축키 | ⌘K 빠른 찾기(초성 포함), 목록 우클릭으로 처리, 내보내기, Finder에서 보기, 삭제 |
| scanshelf:// 링크, 파일 열기 | 기존 사진과 PDF를 Finder에서 scanshelf로 열어 문서로 가져오기 |
| 모델 이어 받기 | 곡면 보정, 인페인팅 모델을 조각 병렬로 받고 끊기면 이어 받기 |
| 캘린더로 묶음 추천 | 촬영 시각과 겹치는 일정을 후보로 넘기고 AI가 OCR 내용으로 확인해 박람회명 추천. 시간 겹침만으로 붙이지 않음 |
| iPhone 동작 버튼, 단축어 | "스캔 시작" 앱 인텐트로 바로 촬영 화면 |
| iPhone 새 버전 알림 | 새 버전이 있으면 AltStore로 여는 안내 |

하지 않는 것: People 명함첩 연동(사용자 보류, 2026-11-05), Raycast 확장(MCP와 빠른 찾기로 충분해 보류).
